# Sabarigirivasan KR Portfolio

## Run locally

1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the localhost URL shown by Vite.

## Build for production

npm run build

## Deploy later

Push this project to GitHub, then import the repository into Vercel.

## Before deploying

- Replace project placeholder text with your real GitHub repository links.
- Add certificate links/images if you want.
- Review phone/email visibility before publishing.
